# Biological-motion stimulus assets

Original videos are **not included** in this public-repository template because redistribution permission has not been established. Obtain authorised source videos and put the complete 80 main-condition MP4 files and the practice files here. Do not commit stimulus videos unless permissions allow it.

Naming: `U|S` + noise `12|24|48|96|192` + direction `L|R` + position `-20|-10|0|10|20` + `.mp4` (example: `S24L0.mp4`). The software requires all 80 main-condition combinations for the standard experiment.

Check video hashes and licensing with the original stimulus provider before release.
