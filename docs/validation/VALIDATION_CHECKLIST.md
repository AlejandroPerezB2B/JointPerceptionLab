# Validation checklist for a future research release

- [ ] Verify source stimulus identity, provenance, permissions, file hashes and decode metadata on both computers.
- [ ] Compare displayed point-light geometry and contrast to the authorised source videos.
- [ ] Measure stimulus onset/offset and frame pacing with external hardware.
- [ ] Measure host/client visual onset difference with an external common reference.
- [ ] Check Y/N and numeric-response accuracy, RT reference event and invalid-response handling.
- [ ] Test shared connection, host-first workflow, disconnections and abort handling.
- [ ] Verify biological-motion 80-condition coverage and transition counts for many seeds.
- [ ] Verify bisection geometry, labels, viewing distance and protocol equivalence.
- [ ] Test full-session completion and CSV row counts on target PCs.
- [ ] Verify data are not written to Git-tracked directories and participant identifiers are pseudonymous.
- [ ] Validate the Windows packaged executable on a clean machine.
- [ ] Record study-specific ethical approval and freeze a versioned release.
