## Software and apparatus

The experimental tasks were implemented in Joint Perception Lab (version 0.6), a Python desktop application using a PySide6 experimenter interface, PsychoPy for full-screen visual presentation, OpenCV for video decoding, and TCP sockets for coordination of dyadic sessions. The software supported individual and dyadic versions of two tasks: biological-motion detection and numerical line-marker localisation. In dyadic sessions, one computer acted as host and the other as client. Both participants received the same ordered stimulus sequence and entered responses independently. The application exchanged readiness and response messages over a local network; the protocol provided trial-state coordination but did not enforce hardware-synchronised visual onset. ## Biological-motion stimuli and factorial design

Biological-motion stimuli consisted of point-light animations encoded as video files. Filenames specified the presence of an intact walker (`U`) or a scrambled stimulus (`S`), the noise level (24, 48, 96 or 192 for the main task), walking direction (left or right) and spatial position (−20, −10, 0, +10 or +20). The full factorial combination comprised 2 × 4 × 2 × 5 = 80 distinct main-task stimuli. Each stimulus appeared once in each of two 80-trial blocks, yielding 160 main trials per participant. Each block therefore contained 40 walker-present and 40 walker-absent trials, with equal marginal representation of noise level, direction and position. ## Biological-motion trial ordering

The main-trial order was generated using constrained pseudorandomisation that balanced first-order transitions between walker-present and walker-absent categories within each block. Specifically, a randomised Eulerian circuit was constructed over a binary directed multigraph containing 20 copies of each transition type (absent→absent, absent→present, present→absent and present→present). This produced an 80-trial cyclic signal sequence with 20 occurrences of each transition type. Because the presented block was linear, the 79 observed within-block transitions comprised 19 occurrences of one transition type and 20 occurrences of each of the remaining three. The hypothetical last-to-first transition used for balancing was not presented. The transition between blocks was not constrained. The 40 distinct video files in each signal category were shuffled and assigned to the corresponding positions in the signal sequence, so transitions involving noise level, direction and spatial position were not explicitly balanced. The same video could not repeat within a block, although repetition across the block boundary was possible.

For individual sessions, the application generated a new 64-bit seed for each session. For dyadic sessions, both computers deterministically derived the same seed from the shared session label and independently generated identical sequences; an ordered-filename digest was checked during the network handshake. Session metadata and complete trial orders were retained for audit.

## Biological-motion procedure and measures

A practice phase contained 10 trials, five walker-present and five walker-absent, selected using a fixed pseudorandom seed and preferentially drawn from noise level 12. Each trial began with a central fixation cross for approximately 500 ms, followed by presentation of the source-video frames. Participants then answered whether a human walker was present using Y (yes) or N (no), without a programmed response deadline. Reaction time was referenced to the response-question display rather than video onset. Practice responses were followed by approximately 800 ms of correctness feedback. Main trials were followed by a 300–500 ms black intertrial interval, and a participant-controlled rest screen separated the two 80-trial blocks. Accuracy, hits, misses, false alarms, correct rejections and response times were saved for each completed trial; software-side presentation timestamps and source-frame indices were logged for timing quality control.

## Numerical line-bisection / marker-localisation task

In the current prototype, participants viewed a horizontal white line on a black background, with endpoints labelled −1000 and +1000 and a vertical white marker placed at a target numerical position. Seventy-three targets from −900 to +900 in increments of 25 were presented twice each, yielding 146 main trials. The 146 trials were shuffled using the fixed seed 20260427, and the resulting sequence was the same for all participants and dyads. Three provisional practice targets (−750, 0 and +750) preceded the main task. Participants entered a signed integer from −1000 to +1000 and confirmed their response by pressing Enter; the target remained visible until a valid response. Reaction time was measured from initial target display to response confirmation. Signed error was defined as response minus target, and absolute error as the absolute value of signed error. ## Dyadic coordination

For shared sessions, the host was started first and listened on TCP port 48321; the client then connected to the host's IPv4 address. The two instances checked the shared session label and trial-order digest. The application used readiness barriers to coordinate trial progression, exchanged responses after each trial, and retained independent participant-level output files. In the bisection task, both responses had to be received before either participant could trigger the next trial by pressing Space. No common display clock, photodiode or external synchronisation trigger was implemented in version 0.6. Consequently, the current implementation does not establish simultaneous physical stimulus onset across monitors.

## Data quality and reproducibility

The application recorded participant/session metadata, trial-order CSV files, trial-level behavioural records and, for biological motion, software presentation timestamps and frame-event logs. Video duration quality control compared expected duration calculated from decoded source-frame count and frame rate with software-measured presentation intervals. These metrics support detection of potential scheduling irregularities but do not directly measure light output or prove that all source frames appeared for their intended durations.
